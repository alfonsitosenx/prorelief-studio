# ProRelief Studio

Windows app by [Excess Pro Net LLC](https://excesspronet.com) that turns a depth map or photo into a watertight, CNC-ready bas-relief STL mesh.

**This repository hosts the downloads only — it contains no source code.**

## Download

**[Latest release](https://github.com/alfonsitosenx/prorelief-studio/releases/latest)** — `ProReliefStudio-4.1.2-Setup.exe` (218 MB)

Everything needed to build relief meshes is inside the installer. Nothing downloads on first run, and the relief engines work with no internet connection at all.

## What it does

Seven relief engines, each suited to different work — round plates and medallions, flat wall panels, lettering, lace and feather detail. Every export is a watertight, manifold STL with a flat base, ready for Aspire, VCarve, Fusion or any CAM package.

- Depth-map and photo input, with a live 3D preview
- Physical sizing in millimetres, with relief height, base plate, prominence, plate bowl and crispness controls
- Mesh tolerance from 0.20 mm down to 0.02 mm
- Batch a whole folder in one run

## Requirements

- Windows 10 or 11, 64-bit
- 8 GB RAM, about 1.1 GB of disk space (2 GB free recommended)
- Internet only for licence activation
